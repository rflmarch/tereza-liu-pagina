Política de privacidade

A Tereza Liu é uma assistente pessoal usada somente por Rafael Marchesano, nas contas Google dele.

  • O que acessa: e-mails do Gmail, com permissão somente de leitura (gmail.readonly).
  • Para quê: identificar mensagens importantes (por exemplo, de bancos e órgãos do governo) e avisar o dono.
  • O que não faz: não envia, apaga nem altera e-mails; não vende, compartilha nem transfere dados a terceiros; não usa os dados para publicidade nem para treinar modelos de IA.
  • Onde ficam os dados: o processamento acontece no computador do dono. O conteúdo dos e-mails não é armazenado; fica guardado apenas um registro técnico (horário e quantidade lida).
  • Como revogar: a qualquer momento em myaccount.google.com/permissions.

Uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
